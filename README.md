# 🌿 Plant Disease Detection using Deep Learning

I built a deep-learning model that takes a photo of a plant leaf and detects whether the plant has a disease. I made it so farmers and plant owners can identify problems early, before they spread and cause crop loss.

## 📌 At a glance
| | |
|---|---|
| **What it does** | Detects plant diseases from leaf images |
| **Who it's for** | Farmers and plant owners |
| **Model accuracy** | Improved from 85% to 98% through repeated testing and refinement |
| **Interface** | Drag-and-drop image upload, designed for mobile and desktop screens |
| **Status** | Ongoing since January 2023 |
| **Author** | Lalit Mali |

## 🎯 The problem
Plant diseases are hard to spot early by eye, and late detection leads to crop loss. I wanted a tool where anyone can upload one leaf photo and get a disease prediction.

## 🔧 What I built
- **A deep-learning model** trained on leaf images to detect plant diseases.
- **A tested and refined model.** My first version reached 85% accuracy. I tested and refined it repeatedly until it reached 98%.
- **An upload interface.** I designed a simple drag-and-drop image upload that works on both mobile and desktop.
